# App Icon Placeholder

Place your app icon here!

## Requirements
- **Filename**: app_icon.png
- **Size**: 1024x1024 pixels (minimum)
- **Format**: PNG with transparency
- **Quality**: High resolution, not scaled up

## Quick Start

1. **Design your icon** using Figma, Canva, or any image editor
2. **Export as PNG** at 1024x1024 pixels
3. **Save here** as `app_icon.png`
4. **Run generator**:
   ```bash
   dart run flutter_launcher_icons
   ```

## Design Tips

- Keep it simple and recognizable
- Use high contrast colors
- Test at small sizes (48x48)
- Center important elements
- Avoid thin lines and text
